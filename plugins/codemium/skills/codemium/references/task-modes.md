# Task Modes

## BUILD
Prefer reuse, native capability, minimal architecture, explicit acceptance.

## FIX
Evidence/reproduction, trace root cause, shared fix, regression proof.

## TEST
Coverage follows behavior/risk/edge cases. Do not minimize test count merely to reduce LOC.

## REFACTOR
Preserve behavior, reduce demonstrated complexity, constrain scope, prove equivalence.

## REVIEW
Correctness → scope → architecture → security → tests → compatibility/performance → complexity.

## MIGRATION
Compatibility, data integrity, staged transition, rollback/recovery, production observability.

## SECURITY
Trust boundaries, validation, authn/authz, secrets, injection/data exposure, fail-safe behavior. Efficiency is subordinate.
